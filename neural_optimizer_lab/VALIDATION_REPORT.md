# Звіт перевірки OptiLab

Перевірки виконані в локальному середовищі розробки 23 жовтня 2026 року.

## Середовище

- Python 3.13.5
- NumPy 2.3.5
- Matplotlib 3.10.8
- scikit-learn 1.8.0
- pandas 2.2.3
- Tkinter доступний

## Автоматичні тести

Команда `python -m unittest discover -s tests -v` завершилася успішно: **16 тестів пройшли, 0 помилок**. Зокрема, перевірені точні контрольні оновлення чотирьох оптимізаторів, стабільність BCE для великих логітів, форми матриць, відтворюваність даних і результатів та збереження таблиць і зображень.

Градієнти backpropagation порівнюються з центральними скінченними різницями для всіх елементів параметрів; поріг тесту для максимальної абсолютної похибки — `2e-6`.

## Додаткова перевірка експериментального конвеєра

Окремо виконано тестову серію з трьома наборами даних (`moons`, `circles`, `xor`), чотирма оптимізаторами, трьома швидкостями навчання та двома повтореннями: **72 із 72 запусків завершилися без числової помилки**, було створено 21 PNG-графік і всі файли результатів. Для цієї швидкої перевірки використовувалися 30 епох і 200 прикладів на набір; це перевірка працездатності, а не завершений науковий висновок.

Вікно Tkinter також було створене під віртуальним X-сервером; перевірено початкові налаштування, заповнення таблиці й відображення збереженого графіка в інтерфейсі.

Тестові результати цієї серії записувалися в тимчасову теку й не включені в ZIP як нібито результати користувацького дослідження. Після першого запуску в VS Code програма створить нову теку `results/` зі справжніми результатами вибраної конфігурації.

## Межі перевірки

Перевірено програмну логіку та графічний інтерфейс у тестовому середовищі. Через відмінності операційних систем, дисплеїв та апаратного забезпечення час виконання й зовнішній вигляд на комп'ютері користувача можуть відрізнятися. Рекомендовано запустити описаний набір автоматичних тестів після встановлення залежностей у власному `.venv`.
